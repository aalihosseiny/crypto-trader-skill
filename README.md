# Crypto Trader Skill · اسکیل معامله‌گر کریپتو برای Claude

<div dir="rtl">

**۱۲ اسکیل Claude برای بازار ارز دیجیتال روی نوبیتکس و والکس:** کیف پول نهنگ‌ها رو کپی می‌کنه، اخبار و حال‌وهوای بازار رو زیر نظر داره، تحلیل تکنیکال می‌کنه، هشدار قیمت می‌ده، هر خرید رو با بودجه‌ات اندازه می‌گیره، و **هیچ سفارشی رو بدون «بله»ی خودت نمی‌فرسته.**

- رایگان، MIT، بدون ثبت‌نام
- ابزارها پایتون ساده‌ان (فقط کتابخانه‌ی استاندارد، بدون `pip install`)

- قیمت‌های تومانی همه‌جا **به تومان** نمایش داده می‌شن (API نوبیتکس ریالی جواب می‌ده و ابزار خودش تبدیل می‌کنه)

## نصب

**روش ۱: پلاگین Claude Code**

```
/plugin marketplace add aalihosseiny/crypto-trader-skill
/plugin install crypto-trader-skill@crypto-trader-skill
```

در این حالت دستورها با پیشوند ظاهر می‌شن، مثل `/crypto-trader-skill:crypto-whales`.

**روش ۲: کپی پوشه‌ها** (دستورهای کوتاه مثل `/crypto-whales`)

```
git clone https://github.com/aalihosseiny/crypto-trader-skill.git
cp -r crypto-trader-skill/crypto-* ~/.claude/skills/
```

برای نصب فقط روی یک پروژه، همین پوشه‌ها رو در `.claude/skills/` همون پروژه کپی کن.

**پیش‌نیاز:** Python 3.8 یا جدیدتر. همه‌ی داده‌هات در پوشه‌ی `crypto/` کنار پروژه ذخیره می‌شه (یا هر جایی که `CRYPTO_DIR` نشون بده).

> ⚠️ **نوبیتکس فقط از IP ایران جواب می‌ده.** این اسکیل‌ها رو روی کامپیوتر خودت در ایران اجرا کن، نه روی سرور خارجی.

| `/crypto-margin` | اهرم (تعهدی) | معاملات تعهدی نوبیتکس: لانگ و شورت با اهرم، انتقال وجه تضمین، نمایش قیمت لیکوئید و فاصله تا آن، حد ضرر و بستن موقعیت. همه با تیکت و «بله». در حالت paper لیکوئید شدن هم شبیه‌سازی می‌شه. |

| `/crypto-pnl` | سود و زیان | قیمت تمام‌شده‌ی هر خرید (lot)، سود و زیان تحقق‌یافته و نیافته به تومان یا تتر، و اینکه فروش یک مقدار مشخص چه سودی می‌ده. |

## جریان کار

همه‌چیز در پوشه‌ی `crypto/` ذخیره می‌شه و هر اسکیل از خروجی اسکیل قبلی استفاده می‌کنه:

```
whales copy  -> budget -> risk -> broker        (کپی یک نهنگ)
ta scan      -> budget -> risk -> broker        (انتخاب با تحلیل تکنیکال)
news / alerts / whales check                    (نظارت، روی زمان‌بندی)
rebalance / pnl -> risk -> broker               (نگهداری پورتفو)
```

### یک مثال: ۵۰ میلیون تومان، کپی یک کیف پول

۱. **`/crypto-whales`** «این کیف پول رو کپی کن: 0x...، ۵ کوین اول»
   دارایی‌ها رو با قیمت دلاری می‌خونه. استیبل‌کوین‌ها رو کنار می‌ذاره و WETH رو ETH حساب می‌کنه. کوین‌هایی که در نوبیتکس نیستن حذف می‌شن. خروجی در `crypto/targets.json` نوشته می‌شه.

۲. **`/crypto-budget`** «۵۰ میلیون تومان، ۱۰٪ نقد، هیچ کوینی بیشتر از ۲۵٪ نباشه»
   نتیجه مثلاً این می‌شه: BTC ۱۲٬۵۰۰٬۰۰۰، ETH ۱۲٬۵۰۰٬۰۰۰، SOL ۱۲٬۰۰۰٬۰۰۰، TON ۸٬۰۰۰٬۰۰۰ تومان و ۵٬۰۰۰٬۰۰۰ نقد. سفارش‌ها به‌صورت پیشنهادی در `crypto/orders.json` ذخیره می‌شن.

۳. **`/crypto-risk`** همه رو چک می‌کنه: کهنه نبودن قیمت، فاصله‌ی خرید و فروش، حداقل سفارش، سقف هر کوین و بافر نقدی. نتیجه‌ی هر سفارش PASS یا BLOCK است، با دلیل.

۴. **`/crypto-broker`** تیکت رو نشون می‌ده، مثلاً:
   «PAPER · خرید 0.001775 BTC با حداکثر قیمت ۷٬۰۴۰٬۰۰۰٬۰۰۰ تومان (حدود ۱۲٬۵ میلیون تومان)، سفارش LIMIT در نوبیتکس. برای ثبت بنویس بله.»
   تو جواب می‌دی و سفارش ثبت می‌شه. بعد سراغ سفارش بعدی می‌ره.

۵. **روی زمان‌بندی:** `/crypto-news` هر صبح گزارش بده، `/crypto-alerts` هر نیم ساعت هشدارها رو چک کنه، و `/crypto-whales check` تغییرات نهنگ‌ها رو گزارش بده.

۶. **هر ماه:** `/crypto-rebalance`.

## اهرم (معاملات تعهدی نوبیتکس)

اهرم به‌صورت پیش‌فرض **خاموشه**. برای روشن کردنش در `crypto/config.json` این مقدارها رو بذار:

```json
"allow_leverage": true,
"max_leverage": 2,
"max_margin": {"IRT": 1000000, "USDT": 50},
"max_open_positions": 3,
"min_liq_distance_pct": 15
```

روند کار:

۱. **«بازارهای تعهدی رو نشون بده»**. در نوبیتکس معمولاً بازارهای **تومانی فقط شورت** دارن و **لانگ روی بازارهای تتری** است.
۲. **«یک میلیون تومان به کیف‌پول تعهدی منتقل کن»**
۳. **«شورت بیت‌کوین با ۵۰۰ هزار تومان وجه تضمین و اهرم ۲»**. تیکت شامل قیمت تخمینی لیکوئید و فاصله‌ی قیمت فعلی تا اون است. «بله» بدی ثبت می‌شه.
۴. **«حد ضرر بذار روی ۷٫۵ میلیارد»**. حد ضرر باید بین قیمت فعلی و قیمت لیکوئید باشه.
۵. **«موقعیت‌هام؟»** سود و زیان، قیمت لیکوئید و فاصله تا اون رو نشون می‌ده. زیر ۱۰٪ فاصله هشدار DANGER می‌ده.
۶. **«موقعیت رو ببند»**

قیمت لیکوئید با این فرمول‌ها تخمین زده می‌شه (نوبیتکس در نسبت تعهد ۱٫۱ لیکوئید می‌کنه):

- لانگ: `ورود × ۱٫۱ × (۱ − ۱/اهرم)`. با ۲x حدود ۴۵٪ ریزش، با ۵x حدود ۱۲٪.
- شورت: `ورود × (۱ + ۱/اهرم) ÷ ۱٫۱`. با ۲x حدود ۳۶٪ رشد.

بعد از باز شدن موقعیت، عدد خود نوبیتکس نمایش داده می‌شه. هر موقعیت حداکثر ۳۰ روز باز می‌مونه و کارمزد تمدید روزانه داره.

## روال روزانه (`/crypto-daily`)

برای کسی که تخصص ترید نداره و می‌خواد روزی یک بار سر بزنه. فقط بنویس:

```
/crypto-daily
```

یا «معامله‌های امروز رو پیدا کن». Claude این کارها رو انجام می‌ده:

۱. نتیجه‌ی موقعیت‌هایی که از دیروز بسته شدن (حد سود یا حد ضرر) رو می‌گه. اگه موقعیتی OCO نداره، براش OCO پیشنهاد می‌ده.
۲. همه‌ی بازارهای تعهدی رو روی نمودار روزانه و ۴ساعته تحلیل می‌کنه. فقط جاهایی رو نگه می‌داره که هر دو هم‌جهت‌اند، نسبت سود به ضرر **بعد از کارمزد** حداقل ۱٫۸ است، و قیمت لیکوئید حداقل ۱۰٪ آن‌طرف‌تر از حد ضرره.
۳. با اخبار، فاندینگ و آنلاک‌ها فیلتر می‌کنه.
۴. یک جدول می‌ده: ارز، جهت، ورود، حد ضرر، حد سود، نسبت سود به ضرر، تخمین روز، قیمت لیکوئید، حداکثر ضرر و سود احتمالی به تومان. **اول سریع‌ترها و پرسودترها.**
۵. با «بله» (یا «بله ۱») موقعیت باز می‌شه و به‌محض پر شدن OCO (حد سود + حد ضرر) روش ثبت می‌شه. لازم نیست تا روز بعد چک کنی.

پیش‌فرض‌ها: ۳۰۰ هزار تومان وجه تضمین، اهرم ۲، حداکثر ۲ معامله‌ی جدید در روز. هر کدوم رو می‌تونی با یک جمله عوض کنی. اگه هیچ معامله‌ای از فیلترها رد نشد، جواب «امروز معامله نکن» است، که خودش یک نتیجه‌ی درسته.

## بک‌تست (`/crypto-backtest`)

جواب این سؤال: «اگه هر روز طبق جدول `crypto-daily` معامله کرده بودم، چی می‌شد؟»

```
python3 crypto-backtest/backtest.py fetch --days 1095   # سه سال کندل روزانه و ۴ساعته
python3 crypto-backtest/backtest.py run                 # قوانین فعلی روی کل تاریخچه
python3 crypto-backtest/backtest.py walkforward         # آزمون خارج از نمونه
python3 crypto-backtest/backtest.py adopt               # فقط اگه توصیه بشه
```

**بدون نگاه به آینده:** تصمیم هر روز فقط با کندل‌های بسته‌شده گرفته می‌شه. ورود با open کندل ۴ساعته‌ی بعدی است. اگه یک کندل هم به حد سود رسید هم به حد ضرر، **ضرر** حساب می‌شه. گپ قیمت با open پر می‌شه. لیکوئید، انقضای ۳۰ روزه و همه‌ی کارمزدها لحاظ می‌شن.

**جلوگیری از overfitting:**

- قانون‌های پیش‌فرض قبل از هر آزمونی تعیین شده‌ان.
- جستجوی پارامترها فقط ۹ ترکیب داره.
- walk-forward: روی ۳۶۵ روز انتخاب می‌کنه، روی ۹۰ روز بعدی که ندیده قضاوت می‌کنه، و جلو می‌ره. فقط پنجره‌های دیده‌نشده حساب می‌شن.
- تنظیم جدید فقط وقتی پذیرفته می‌شه که خارج از نمونه از پیش‌فرض بهتر باشه **و** همسایه‌هاش در جدول پارامترها هم مثبت باشن، یعنی یک نقطه‌ی شانسی نباشه.
- هر عدد بازه‌ی اطمینان ۹۰٪ داره. زیر ۳۰ معامله، به‌جای عدد گفته می‌شه «کمتر از اونه که بشه قضاوت کرد».

**در جدول روزانه** برای هر معامله یک ستون «شانس» اضافه می‌شه، مثلاً «۴۴٪ (۳۷ تا ۵۱٪، ۱۴۰ معامله)، نقطه‌ی سر به سر ۳۶٪». این عدد درصد معامله‌های مشابه در گذشته است که با سود بسته شدن. وعده نیست.

## راه‌اندازی معامله‌ی واقعی (فقط وقتی مطمئن شدی)

۱. اول چند هفته با **paper** کار کن: `broker.py paper-init --cash 50000000`
۲. اگه می‌خوای، روی **تست‌نت نوبیتکس** امتحان کن: در `testnet.nobitex.ir` حساب بساز، توکن بگیر و `NOBITEX_TESTNET_TOKEN` رو تنظیم کن. بعد `"mode": "testnet"` بذار.
۳. برای **live**:
   - در پنل صرافی یک API key بساز که **فقط مجوز معامله** داشته باشه و **مجوز برداشت نداشته باشه**. اگه صرافی امکانش رو داره، به IP خودت محدودش کن.
   - کلید رو **در ترمینال خودت** تنظیم کن، نه در چت:
     ```
     export NOBITEX_TOKEN=...      # یا
     export WALLEX_API_KEY=...
     ```
   - در `crypto/config.json` مقدار `"mode": "live"` رو بذار.

اگه کلیدی رو اشتباهی در چت گذاشتی، همون لحظه در پنل صرافی باطلش کن و کلید جدید بساز.

## قفل‌های ایمنی

- **هر سفارش یک تیکت داره و یک «بله».** Claude هیچ‌وقت خودش تأیید نمی‌کنه.
- **فقط سفارش‌هایی که از risk گذشتن اجرا می‌شن.** اگه سفارش بعد از چک تغییر کنه، broker ردش می‌کنه (با مقایسه‌ی hash).
- **هر تأیید فقط ۱۰ دقیقه معتبره.** قیمت‌ها تغییر می‌کنن، پس بعدش باید دوباره تأیید کنی.
- **همه‌ی سفارش‌ها LIMIT هستن و محافظ قیمت دارن** (برای خرید حداکثر ask + ۰٫۵٪). سفارش مارکت بی‌حد ثبت نمی‌شه.
- **هیچ سفارشی دو بار فرستاده نمی‌شه.** اگه ارتباط وسط ارسال قطع بشه، سفارش «IN FLIGHT» علامت می‌خوره و تا وضعیتش رو چک نکنی دوباره ارسال نمی‌شه.
- **اهرم** به‌صورت پیش‌فرض خاموشه. وقتی روشنش کنی، سقف اهرم، سقف وجه تضمین، سقف تعداد موقعیت باز و حداقل فاصله تا لیکوئید رو کنترل می‌کنه.
- **کلیدها** فقط از متغیرهای محیطی خونده می‌شن و هیچ‌جا ذخیره یا چاپ نمی‌شن.
- پوشه‌ی `crypto/` (داده‌های شخصی‌ات) در `.gitignore` هست و به GitHub نمی‌ره.

## قوانین (`crypto/config.json`)

نمونه در `crypto-budget/config.example.json`:

| کلید | پیش‌فرض | معنی |
|---|---|---|
| `exchange` | `nobitex` | `nobitex` یا `wallex` |
| `quote` | `IRT` | `IRT` (تومان) یا `USDT` |
| `mode` | `paper` | `paper`، `testnet` یا `live` |
| `cash_buffer_pct` | 10 | درصدی که همیشه نقد می‌مونه |
| `max_position_pct` | 25 | سقف هر کوین از کل پورتفو |
| `min_order` / `max_order` | 300٬000 / 100٬000٬000 تومان | کمترین و بیشترین مبلغ هر سفارش |
| `max_orders_per_day` | 20 | سقف تعداد سفارش در روز |
| `blocked` / `allowed` | — | کوین‌های ممنوع / فقط این کوین‌ها مجازن |
| `max_spread_pct` | 1.5 | بازارهای کم‌عمق رو بلاک می‌کنه |
| `max_price_age_min` | 15 | قیمت قدیمی‌تر از این قبول نمی‌شه |
| `slippage_pct` | 0.5 | محافظ قیمت سفارش LIMIT |
| `approval_ttl_min` | 10 | مدت اعتبار هر تأیید |
| `qty_decimals` | — | تعداد اعشار مقدار هر کوین، اگه صرافی خطای دقت داد |

## محدودیت‌ها

- **این توصیه‌ی مالی نیست.** این نرم‌افزار داده‌های عمومی رو می‌خونه و حساب‌وکتاب می‌کنه. آینده رو نمی‌دونه. کپی کردن یک نهنگ نتیجه‌ی اون نهنگ رو کپی نمی‌کنه، و ممکنه ضرر کنی.
- **برچسب کیف پول‌ها قطعی نیست.** کیف پولی که در سایتی «نهنگ» نام گرفته ممکنه مال صرافی، کاستودین یا بریج باشه.
- **API رایگانی برای آنلاک توکن‌ها نیست.** Claude اون‌ها رو از وب پیدا می‌کنه و با لینک منبع در `crypto/unlocks.json` ثبت می‌کنه.
- **دقت اعشار مقدار سفارش** در نوبیتکس برای هر کوین فرق داره. ابزار یک مقدار معقول حدس می‌زنه، و اگه صرافی خطا داد، با `qty_decimals` تنظیمش کن.
- **مقدار بستن موقعیت تعهدی**: ابزار کل `liability` رو که نوبیتکس برمی‌گردونه می‌فرسته (طبق مستندات). اولین بستن واقعی رو با یک موقعیت کوچک امتحان کن.
- **endpointهای سفارش و موجودی** طبق مستندات رسمی نوبیتکس و SDK والکس نوشته شده‌ان، ولی آفلاین تست شده‌ان (بدون تماس واقعی). **اول روی paper و تست‌نت امتحان کن.**
- **قیمت تومانی** هم حرکت خود کوین رو نشون می‌ده هم نرخ تتر رو.
